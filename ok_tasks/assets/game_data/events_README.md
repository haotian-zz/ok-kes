## 用法提示

- 标题 → 事件：`name` 不唯一（同名变体 a/b/c、gamekee 的「xx1/xx2」），用 OCR 出的全部选项文字和各变体 `options[].text` 做集合匹配再定 id；`(直接攻击)` 选项在画面上通常是攻击按钮而不是文字选项。
- 天上防护墙（gamekee）的说明图是 AI 根据游戏数据生成的，用词混有国际服叫法（战斗员、灵光、判定属性「口才/识破/骗术」，文字也带「著」），**选项文字与国服实际按钮可能有出入**，匹配时要做模糊匹配；生命值等数值没写「增加/减少」，按图里的正负号解析（`生命值 10%` 视为恢复）。gamekee 页面标题与图里标题有两处不同（无法拒绝的触摸/抚触、创世前/创世之前的计划），已放进 `name_aliases`。
- 国际服客户端 OCR 用 `name_intl` / `text_intl`（没有就和国服相同）。
- `requires` 不满足时按钮灰色；`appear_if` 不满足时选项不出现。
- 刷存档：优先 `删2张卡`（多数需要判定或战斗，看 `check`/`kind`），避开 `咒术卡` `降最大生命` `失败塞咒术卡`。
